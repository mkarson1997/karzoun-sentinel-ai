# Changelog

All notable changes to Karzoun SentinelAI are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-04

### Added

- Offline-first, provider-neutral evaluation core for recorded LLM outputs.
- Prompt-injection heuristic evaluator.
- Deterministic groundedness regression baseline.
- Sensitive-output detection with report-safe redaction.
- JSONL dataset loading and validation.
- Deterministic parallel evaluation runner.
- JSON and Markdown reporting.
- Baseline comparison and regression quality gates.
- CLI commands for evaluation and report comparison.
- Workspace-confined file access for CLI inputs and outputs.
- Strict Mypy typing, Ruff linting, and Pytest verification.
- Python 3.11, 3.12, and 3.13 CI matrix.
- Locked Python dependency graph with `uv.lock`.
- Apache-2.0 licensing, security policy, contribution guide, code of conduct, architecture documentation, and roadmap.
- Container packaging for the SentinelAI CLI.
- Automated GitHub Release and GitHub Container Registry publishing.
